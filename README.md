# YouTube UI Clone

A responsive front-end recreation of the YouTube home page, built with HTML and CSS.

## Features

- Fixed navigation header with search, voice search, action icons, and profile image
- Fixed sidebar navigation
- Responsive video-card grid with thumbnails, channel details, titles, and view statistics
- Clickable video titles, thumbnails, channel images, and author names
- Hover effects and tooltips for header controls
- Responsive layouts for desktop, tablet, and mobile screens

## Responsive Layout

| Screen width | Video columns |
| --- | --- |
| 450px and below | 1 |
| 451px–750px | 2 |
| 751px–1024px | 3 |
| 1030px and above | 4 |

## Built With

- HTML5
- CSS3

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/a-5amad/YOUTUBE.git
   ```

2. Open the project folder.

3. Open `youtube.html` in your browser.

## Project Structure

```text
YOUTUBE/

```
